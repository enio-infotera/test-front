## 🔌 Mock API
 
A API mockada está na pasta **`mock-api/`**.
 
### Como rodar:
 
```bash
cd mock-api
npm install
npm run server
```
 
A API estará disponível em: **http://localhost:3333**

O banco reinicia a partir de `db.seed.json` a cada start. Endpoints, filtros, simulação de erro e como hospedar a API estão em [`mock-api/README.md`](mock-api/README.md).
